# Naver GFA (성과형 디스플레이 광고) 통합 마케팅 제안서

본 레포지토리는 디지털 마케팅 환경 변화에 대응하여 **네이버 GFA(Glad For Advertisers)의 도입 필요성과 퍼널별 실행 전략**을 다루는 공통 제안서 및 실행 템플릿 프로젝트입니다.

---

## 📌 주요 수록 내용

1. **디지털 마케팅 시장 환경 변화 분석**
   - 글로벌 매체(Meta/Google) CAC(고객 획득 비용) 폭등 및 쿠키 폐지에 따른 리타겟팅 정밀도 저하
   - 검색광고(SA) 포화 상태 및 입찰가 경쟁 심화 극복
2. **네이버 GFA 핵심 소구점 (Why GFA?)**
   - 독점적 트래픽 & First-party 데이터 기반 '의도(Intent)' 타겟팅
   - AI 최적화 솔루션 (ADVoost 쇼핑 캠페인 & 다이내믹 카탈로그)
   - 풀퍼널(Full-Funnel) 마케팅 시너지 (GFA ➔ SA 브랜드 검색 증대 ➔ 스토어/자사몰 전환)
3. **실전 퍼널별 캠페인 셋업 & 운영 Framework**
   - 상단(TOFU), 중단(MOFU), 하단(BOFU) 퍼널별 타겟팅, 소재, 입찰 전략
   - 최적화 3대 핵심 원칙 (데이터 학습 기간, 소재 파이프라인, 간접 전환 측정)
