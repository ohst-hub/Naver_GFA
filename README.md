# NAVER GFA AI 커스텀 & ADVoost 통합 제안서 (10P Pitch Deck)

네이버 GFA의 차세대 AI 기술인 **UTA 커스텀 타겟팅(자연어 타겟팅)** 및 **ADVoost 오디언스 자동 최적화 솔루션**을 결합한 10페이지 분량의 반응형 가로 슬라이드 웹 제안서입니다.

## 📌 주요 수록 내용
1. **01. 표지 및 핵심 가치 요약**: 신규 70%, ROAS 2.7배 개선, 7종 행동 데이터 전영역 분석 요약
2. **02. 마케팅 시장 3대 위기**: CAC 폭등, 쿠키리스/추적 제한, 검색광고 포화
3. **03. 기존 타겟팅의 3대 한계**: 신규 발굴 한계, 정교한 타겟 정의 불가, 세그먼트 생성 번거로움
4. **04. AI 자연어 타겟팅 (UTA)**: 말로 설명하는 타겟팅, 7종 네이버 행동 데이터 분석
5. **05. ADVoost 오디언스**: 시그널 기반 자동 확장, 간소화된 세팅, 실시간 머신러닝 최적화
6. **06. 검증된 CBT 성과 및 대형 사례**: 대형 스마트폰 브랜드 ROAS 3,853%, CPA -61% 절감 사례
7. **07. 풀퍼널(Full-Funnel) 전략**: 1단계(인지) -> 2단계(탐색) -> 3단계(구매)
8. **08. 실시간 예산 & 성과 시뮬레이터**: 월 예산별 클릭수 및 매출 예측 계산기
9. **09. 실패 없는 실전 운영 5대 수칙**: 학습 기간 1주일, 1,000만원당 2개 세그먼트 가이드
10. **10. 추진 로드맵 & FAQ**: 3단계 실행 일정 및 자주 묻는 질문

## 🚀 깃허브 배포 방법
1. 압축 파일 내의 `index.html`을 GitHub 레포지토리의 최상위(Root) 경로에 업로드합니다.
2. 레포지토리 **Settings > Pages** 메뉴에서 Source를 `Deploy from a branch` (main / root)로 지정합니다.
3. 배포된 URL로 접속하면 가로 전환 슬라이드 제안서가 동작합니다.
