# NAVER GFA 성과형 광고 전략 제안서 (10P 깔끔한 공통 덱)

전체 네이버 GFA의 공통 제안서 흐름을 명확히 잡고, **ADVoost 오디언스**와 **UTA 자연어 타겟팅**을 독립된 페이지로 분리 배치하여 광고주가 쉽게 읽을 수 있도록 구성한 **10페이지 분량의 가로 슬라이드 웹 제안서**입니다.

## 📌 10페이지 목차 구성
1. **01. 시작**: 왜 지금 네이버 GFA인가? (핵심 가치 제안)
2. **02. 시장의 어려움**: 광고비는 오르고 손님은 줄어드는 3대 이유
3. **03. GFA 강점**: 국내 최대 프리미엄 지면과 구매 의도 데이터
4. **04. ADVoost AI**: 힌트만 주면 알아서 확장하는 스마트 타겟팅
5. **05. UTA 자연어 타겟**: 말로 설명하면 완성되는 차세대 타겟팅 (7종 행동 데이터)
6. **06. 풀퍼널 구조**: 관심 ➔ 탐색 ➔ 결제로 이어지는 원스톱 매출 플라이휠
7. **07. 집행 전략**: 퍼널 단계별 황금 예산 배분 비율 (30% : 40% : 30%)
8. **08. 예상 매출 계산**: 월 예산별 유입수 및 기대 매출 실시간 계산기
9. **09. 실전 운영 팁**: 광고비 낭비 없이 최고 효율 내는 4대 수칙
10. **10. 8주 성장 사례**: **대표 4개 업종별(패션/뷰티, 건강식품, 가구/리빙, 가전/IT) 8주간 가상 광고 개선 성장표**

## 🚀 깃허브 배포 방법
1. 압축 파일 내의 `index.html`을 GitHub 레포지토리의 최상위(Root) 경로에 업로드합니다.
2. 레포지토리 **Settings > Pages** 메뉴에서 Source를 `Deploy from a branch` (main / root)로 지정합니다.
3. 배포된 URL로 접속하면 가로 전환 슬라이드 제안서가 동작합니다.
