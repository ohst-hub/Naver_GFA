# NAVER GFA AI 실전 광고 제안서 (10P 가로 슬라이드 덱)

어려운 전문 마케팅 용어를 전부 빼고, 누구나 쉽게 이해할 수 있는 일상 언어와 직관적인 지표로 구성된 **10페이지 분량의 네이버 GFA 웹 제안서**입니다.

## 📌 10페이지 주요 구성
1. **01. 시작**: 말로 설명하면 알아서 찾아오는 네이버 AI 맞춤 광고
2. **02. 광고의 어려움**: 광고비는 오르고 손님은 줄어드는 3가지 이유
3. **03. 기존의 한계**: 메뉴판 체크박스 방식의 한계 3가지
4. **04. 말로 찾는 고객**: 일상 문장 입력과 7가지 진짜 행동 데이터 분석
5. **05. 알아서 찾는 AI**: 시그널 기반 자동 확장과 실시간 최적화
6. **06. 입증된 성과**: 신규 손님 70%, 광고수익률 2.7배 증가 실증 데이터
7. **07. 구매 연결 구조**: 노출부터 네이버페이 결제까지 이어지는 원스톱 플라이휠
8. **08. 예상 매출 계산**: 월 예산별 예상 방문자 수 및 예상 매출 실시간 계산기
9. **09. 실전 운영 팁**: 실패 없이 성과를 내는 4가지 운영 원칙
10. **10. 8주 성장 사례**: **대표 4개 업종별(패션/뷰티, 건강식품, 가구/리빙, 가전/IT) 8주간 가상 광고 개선 레퍼런스**

## 🚀 깃허브 배포 방법
1. 압축 파일 내의 `index.html`을 GitHub 레포지토리의 최상위(Root) 경로에 업로드합니다.
2. 레포지토리 **Settings > Pages** 메뉴에서 Source를 `Deploy from a branch` (main / root)로 지정합니다.
3. 배포된 URL로 접속하면 가로 전환 슬라이드 제안서가 동작합니다.
